| AC-1 | Accuracy | Error | The "Manual payload" placeholder is declared `disabled`, but the proposal and spec also require the user to *select* it to deselect. In the built container the default `data/benchmark.jsonl` is absent, so the new endpoint always returns 404. The file is also untracked in git, and no task commits it. | Dockerfile L18 (`COPY app ./app`), docker-compose.yml L17-32, design.md L56 and L144-145 ("the dataset file ships in the repo"), `git status` → `?? data/`, tasks.md has no packaging/commit task |
