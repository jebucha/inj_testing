### Notes on verified claims (no finding)

- `app/main.py`: POST validates before any filesystem access, ignores unknown keys, rejects an empty recognized-field set, and echoes the file it just wrote via `load_settings`.
- `app/static/app.js`: explicit Light/Dark set `data-theme`; `system` removes it; only `{"theme": ...}` is posted; both select and palette revert on failure; the attribute is re-applied to the iframe on its `load` event. The auto-summarize handler still posts only its own field, so `{"autoSummarize": True}` file assertions hold (13/13 `test_auto_summarize.py` pass).

- Docs regeneration is reproducible: `docs/generate.py` run against a copy of `docs/` produced byte-identical output (`diff -rq` empty), satisfying task 3.4.
